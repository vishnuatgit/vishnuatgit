### [ArchLens](https://github.com/vishnuatgit/ArchLens)

### [DeepBell](https://github.com/vishnuatgit/DeepBell)
*FastAPI, LangChain, Google Gemini, scikit-learn, Prometheus, Grafana, SQLite, Docker* · [Live demo](https://deepbell.onrender.com) · [Case study](https://vishnuatgit.github.io/projects/deepbell.html) ([PDF](https://vishnuatgit.github.io/pdf/deepbell-case-study.pdf))

A self-monitoring SRE lab in FastAPI: it flags CPU and memory anomalies with an Isolation Forest, fires alert rules, traces each incident to a likely cause, writes incident reports with Gemini via LangChain (a built-in template without a key), exports Prometheus metrics and rolls back SQLite snapshots. A seeded benchmark of the real detector found 0 false incidents and 4 s detection. 144 tests, CI passing.

### [SupplyTrace](https://github.com/vishnuatgit/SupplyTrace)
*Python, FastAPI, scikit-learn, Pandas, NumPy, SQLAlchemy, Docker* · [Live demo](https://supplytrace-fkpq.onrender.com) · [Case study](https://vishnuatgit.github.io/projects/supplytrace.html) ([PDF](https://vishnuatgit.github.io/pdf/supplytrace-case-study.pdf))

An ML data pipeline that validates supplier XML invoices, flags duplicate invoices, routes doubtful ones to a review queue with reviewer history and a vendor directory, and adds an experimental Random Forest risk score. Processes 28.9 invoices/s (p95 48 ms) in a local benchmark; 234 tests, CI passing.
